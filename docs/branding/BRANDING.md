# CipherNest Branding

The source mark is an original geometric shield containing layered nest arcs. Editable vector sources live in `src/CipherNest.App/Resources/AppIcon`, `Resources/Splash`, and `Resources/Images`.

- Primary background: `#19222D`
- Primary teal: `#2F7D78`
- Light mark: `#E8F5F2`
- Watermark text: `Made by the Sanskar`

MAUI derives platform icon sizes from the vector source. Android uses the foreground/background adaptive icon inputs. Apple and Windows packaging generate rasterized platform assets during build. Store listing exports should be generated from the same vector at the store-required dimensions; do not add tiny text inside the icon.
